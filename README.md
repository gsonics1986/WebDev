I chose Urban Couture as the name for my Fashion House Website. Urban Couture is a responsive fashion house website developed to showcase the brand's products, services, and upcoming activities through a clean, professional, and user-friendly interface. I built this website using HTML for the structure, CSS for styling, and JavaScript to add interactivity. An external CSS file was used to maintain a consistent design and layout across all pages.

The main website consists of five pages: Home, Products, Board of Trustees, Appointments, and Events. The Home page welcomes visitors and introduces Urban Couture through a hero section and featured collections. The Products page displays a variety of fashion items with their images, descriptions, and prices. The Board of Trustees page presents the members of Urban Couture with their photographs and positions. The Appointments page enables customers to book consultations and styling sessions through an online booking form, while the Events page provides information about upcoming fashion events and allows visitors to register.

To ensure a consistent user experience, all five main pages share the same navigation menu, header, footer, and marquee displaying important announcements. JavaScript is used throughout the website to provide interactive features such as page navigation, product information, event registration, and appointment booking.

In addition to the five main pages, I developed a separate DOM Structure page to illustrate the website's file organization and the Document Object Model (DOM). This page demonstrates the hierarchical relationship between the HTML files, CSS files, JavaScript file, images, and other website components, fulfilling the assignment requirement to present the website's DOM structure.
